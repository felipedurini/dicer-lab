# NCBI RefSeq reference data

The bundled archive contains **Apis mellifera NCBI Annotation Release 104**
RNA sequences for assembly **GCF_003254395.2, Amel_HAv3.1**. It is the complete
annotated transcript set in that release, not a claim of biological completeness.

- Provider: NCBI / National Library of Medicine, RefSeq.
- Assembly submitter: Uppsala University, as identified in the
  [annotation report](https://www.ncbi.nlm.nih.gov/refseq/annotation_euk/Apis_mellifera/104/).
- [Original RNA FASTA archive](https://ftp.ncbi.nlm.nih.gov/genomes/all/annotation_releases/7460/104/GCF_003254395.2_Amel_HAv3.1/GCF_003254395.2_Amel_HAv3.1_rna.fna.gz).
- Retrieval date recorded by the project: 2026-10-29.
- Archive MD5: `5630586536b037fc4c904d13a98c81c8`.
- Archive SHA-256: `f03df1564920b6fa61f73afaa49bf1e27949a4ca5f056eee09c0aa91548a6e34`.
- Expanded FASTA SHA-256: `124a2d9c0b0d395b6350b37a4a0980725f8b69fbbb25bf6079d1f65211a6c28e`.
- 27,887 records; 98,645,700 nucleotide positions. See `catalog.json`.
